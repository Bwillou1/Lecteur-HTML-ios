Lecteur HTML pour iOS & Web

L'application web progressive (PWA) conçue pour ouvrir, prévisualiser et inspecter facilement des fichiers et du code HTML directement sur iPhone, iPad et Safari, entièrement hors-ligne.

Ouvrir le Lecteur HTML →

Fonctionnalités clés

  • Aperçu instantané de tout fichier .html local depuis l'app Fichiers ou iCloud
  • Édition en direct et injection dynamique de balises
  • 100% hors-ligne propulsé par un Service Worker
  • Confidentialité totale : tout est exécuté localement dans votre navigateur
